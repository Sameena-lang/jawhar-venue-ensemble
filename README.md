# Jawhar Collections

Build a premium luxury wedding and event venue platform for Jawhar Groups.

IMPORTANT:

Do NOT create a generic website.

Do NOT create a SaaS dashboard.

Do NOT use random colors.

Create a luxury hospitality experience inspired by premium hotel websites.

Brand Structure:

Jawhar Groups (Master Brand)

Venues:

- Jawhar Grand

- Jawhar Elite AR Tower

- Jawhar Grand Palace

- Venue 4

- Venue 5

Color Palette:

- Pastel Green #C8DDD1

- Pastel Blue #D4E4EA

- Warm Ivory #F8F5ED

- Deep Forest Green #203C32

- Antique Gold #B89A57

- White #FFFFFF

Typography:

- Elegant luxury serif headings

- Clean modern body text

Homepage:

Create a cinematic fullscreen hero with luxury wedding venue imagery.

Headline:

Jawhar Groups

Luxury Wedding Venues &

Premium Event Spaces

Subheadline:

Creating unforgettable celebrations through elegant venues and exceptional hospitality.

Buttons:

- Book Venue

- Explore Locations

- Schedule Visit

Below the hero create a luxury venue collection section showing 5 venue cards.

Each card includes:

- Venue image

- Venue name

- Location

- Capacity

- Short description

- View Details button

When a user clicks a venue card, open a dedicated venue page.

Example:

/venues/jawhar-grand

/venues/jawhar-elite-ar-tower

/venues/jawhar-grand-palace

Each venue page must include:

- Hero banner

- Venue story

- Quick facts

- Facilities

- Gallery

- Events supported

- Services

- Availability calendar

- FAQ

- Contact

- WhatsApp enquiry

- Location map

- Schedule visit button

Create a premium masonry gallery with:

- Category filters

- Fullscreen lightbox

- Mobile swipe support

- Image captions

Create an Events section:

- Wedding

- Reception

- Engagement

- Seemantham

- Birthday

- Anniversary

- Corporate

Selecting an event updates venue recommendations and services.

Create a Services section:

- Venue

- Catering

- Decoration

- Photography

- Videography

- Accommodation

- Event Coordination

Create an Availability section:

- Venue selection

- Date selection

- Session selection

- Guest count

- Availability status

Create a guided enquiry experience:

Step 1 Event Type

Step 2 Date

Step 3 Guests

Step 4 Services

Step 5 Contact Details

Include:

- WhatsApp enquiry

- Contact form

- Share venue

- Testimonials section

- FAQ section

Use Framer Motion for:

- Hero reveal

- Section animations

- Image reveals

- Smooth page transitions

- Card hover effects

Ensure:

- Mobile-first design

- No horizontal scrolling

- Fast loading

- SEO-ready structure

- Accessibility support

- Reusable venue architecture

The homepage must feel like a premium 5-star hospitality brand website.

Use the same design language, color palette and layout system across all five venues while allowing each venue to have its own content and gallery.

Make the overall experience elegant, cinematic, premium, responsive and trustworthy.
